# Grade Calculator

A simple and responsive Grade Calculator built using HTML, CSS, and JavaScript. It calculates and displays grades based on the marks entered by the user.

## Features

- Enter student marks
- Calculate grades automatically
- Input validation
- Simple and responsive user interface
- Instant result display

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
